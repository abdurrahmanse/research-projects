# 03 · Literature Review and Research-Gap Analysis

## 0. How this was built, and its limits
- Searches (web search, 2026-11-01) for PPD/PPA machine learning, explainable ML, ensemble/stacking, calibration/PROBAST, and for studies using the same Kaggle dataset. **Google Scholar, IEEE Xplore, ACM DL, ScienceDirect and SpringerLink were not directly searchable**; coverage is therefore *not systematic*. Treat this as a verified starting set, not a systematic review. A PRISMA-style search is listed as a to-do in `14`.
- Verification levels: **V1** = full page read by a fetch tool (title, authors, venue, DOI confirmed); **V2** = confirmed only from search snippets or from another paper's description → re-check before citing; **V3** = recalled methodological reference, not fetched.
- Where a fetch tool returned only a partial page (marked "S" in my notes), I report only what appeared in verbatim text and flag the rest as unverified. No metric below was invented.
- **Performance numbers across rows are not comparable**: outcomes (EPDS ≥9/≥10/≥12/≥13, PHQ, ICD codes), prevalence (1.9%–36%), populations and validation differ.

### What the matrix shows (verified rows only)
- **Calibration** is explicitly reported in 1 of the 13 primary-model studies I read (L15; plus Brier in two of the studies summarised by L11). Others: "not stated."
- **External or temporal validation** appears in L5 and L13 (and per snippet L19). Where it appears, performance falls (L13: 0.91 → 0.77; L12 cross-dataset: 0.733 → 0.646). Internal-only AUCs should therefore be read as optimistic.
- **Explainability** is overwhelmingly post-hoc SHAP on one model, with no stability testing in any verified study.
- **Anxiety as an outcome** is rare (L7, L14 only among verified rows); none targets self-report anxiety items with a leakage-aware design.
- **Stacking/ensembles**: L4 (stacked ensemble considered, XRT chosen) and L15 (stacking + voting). Neither gives a head-to-head test of significance against the best single learner (as far as I read).
- **Same-dataset** work (L16, L17) shows very high accuracy without any described validation, calibration, explainability, or duplicate handling.

## 3. Do hybrid/explainable-ensemble PPD approaches already exist?
Yes. Voting/stacking ensembles with SHAP exist [L15 (stacking + SHAP + calibration, EPDS outcome, two hospitals); L13 (SHAP, tiers, temporal cohort); L4 (stacked ensemble considered)]. **Therefore "explainable ensemble ML for PPD" is not novel.** Any claim must instead rest on: the leakage-aware design, formal significance testing of ensemble gains, calibration-conditioned tiering, explanation stability, and a minimal-item screener. See `10`.
