## 🚀 Getting Started

### Prerequisites
- Python 3.9+ installed
- Git installed
- A terminal (Mac/Linux) or PowerShell (Windows)

### Quick Setup
```bash
# Clone the repository
git clone https://github.com/your-username/Data-Scientist-Tool-Stack.git
cd Data-Scientist-Tool-Stack

# Create a virtual environment
python -m venv ds_env
source ds_env/bin/activate  # Mac/Linux
# ds_env\Scripts\activate   # Windows

# Install core dependencies
pip install jupyter numpy pandas matplotlib seaborn scikit-learn

# Launch Jupyter
jupyter notebook
```
