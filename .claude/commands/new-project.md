Create a new project for: $ARGUMENTS

1. Read `docs/project_template.md` and the README of the latest existing project.
2. Pick the next number `NN` and create `NN-<slug>/` with README.md, requirements.txt, data/, notebooks/, results/, research/.
3. Write a README skeleton with the research question, hypotheses (marked "to fix before main run"), planned metrics and validation scheme.
4. Add the project row to the root README table with status "Planning".
Do not commit.
