# Research Blueprint

**Title:** Interpretable Postpartum Anxiety Symptom Screening Using a Hybrid Ensemble and Explainable AI

**Main notebook:** `notebooks/final_thesis_study.ipynb` (47 tasks, one per cell; the dataset is only read). Outputs go to `results/final/`.

**Method in one sentence:** five algorithms (LR, RF, ET, SVM and a soft-voting Hybrid Ensemble of RF + ET + SVM) compared under leakage-free repeated cross-validation, with SHAP and LIME explanations.

Docs 04–08 describe the earlier CGTH design; doc 09 is the final design.
